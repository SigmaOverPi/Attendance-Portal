# Attendance Portal (Individual)
This repository contains the code and documents for Activity 3.1 of the Web Technologies Weekly Labs

## Features Implemented:
- User signup and login updated with PHP
- Student attendance dashboard which fetched attendance info from the database and populates the dashboard with it
- An email template generator, which allows students to raise attendance issues easier

## Technologies Used:
- PHP
- XAMPP
- MySQL
- HTML
- CSS
- JavaScript

## Setup Instructions:
- Create activity folder in XAMPP's htdocs folder(in this case, the folder was named activity_03)
- Import database
- Navigate to 'localhost/activity_03'
